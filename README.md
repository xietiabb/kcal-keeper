# 热量管家 · 减肥饮食记录 App

为个人量身定制的减肥饮食记录工具。核心规矩：**不拍照，不给记**。

## 核心功能

- 📷 **强制拍照记录**：每一餐必须先拍照（直接调起手机相机），不拍照无法保存，杜绝"随手填个数字糊弄自己"
- ✍️ **手动录入营养数据**：克数 + 配料表营养值（能量 / 蛋白质 / 碳水 / 脂肪），支持"按每100克抄配料表"和"直接填这餐总量"两种模式
- 🔥 **热量环 + 剩余额度**：今日已摄入 / 目标热量一目了然，超标变红警告
- 📅 **历史回看**：月历打卡视图，每天的营养汇总，近7天日均、超标天数统计
- ⚖️ **体重管理**：记录体重、趋势折线图、减重进度条
- 🎯 **目标建议**：按 Mifflin-St Jeor 公式算基础代谢和 TDEE，自动建议每日热量目标
- 🔥 连续打卡天数，督促坚持
- 💾 **数据全本地**：数据只存在手机本地（IndexedDB + localStorage），不上传任何服务器；支持一键导出 JSON 备份

## 把它装到手机

### 方式 A：在线版安装（推荐，可离线）

1. 手机浏览器打开本项目的 GitHub Pages 链接
2. 浏览器菜单（⋮ 或分享按钮）→ **添加到主屏幕 / 安装应用**
3. 桌面出现"热量管家"图标，点开即用，PWA 支持离线

### 方式 B：USB 传文件

1. USB 连接手机，把整个项目文件夹拷到手机存储
2. 手机浏览器打开 `index.html`
3. 同样"添加到主屏幕"

> 注意：拍照功能依赖浏览器相机权限，USB 文件方式在部分安卓浏览器上可能受限，优先用方式 A。

## 使用建议

- 拍照时把食物和**包装配料表**一起拍，抄每100克营养值最方便
- 每天固定时间（如早起空腹）称体重更准
- 数据建议每周导出一次备份

## 技术说明

单文件 PWA（`index.html` 内联全部 CSS/JS），零依赖、零后端、零跟踪。

- `manifest.json` — PWA 应用清单
- `sw.js` — Service Worker 离线缓存
- `icon-*.png` — 应用图标
